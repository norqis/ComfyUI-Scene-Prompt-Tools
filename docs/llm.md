# LLM と LoRA 検索

[README に戻る](../README.md) · [Scene の組み立てと保存](workflows.md) · [プロンプトデータ](prompt-data.md)

Scene Prompt (LLM) は、書きたい内容の説明からポジティブ・ネガティブのプロンプトを作るノードです。OpenAI 互換 API を持つ LLM サーバーへ接続します。利用は任意で、通常の Scene Prompt だけでも画像を生成できます。

## LLM を接続する

Scene Prompt (LLM) の **LLM接続設定** を開き、利用するサーバーの情報を入力します。LLM サーバー自体はあらかじめ起動してください。このツールがサーバーを起動することはありません。

| 項目 | 入力内容 |
| --- | --- |
| API URL（必須） | OpenAI 互換 API の URL。初期値は `http://127.0.0.1/v1` |
| ポート（任意） | 初期値は `8080`。空欄なら HTTP/HTTPS の既定ポートを使用 |
| モデル名（任意） | 空欄ならサーバーの既定モデル。モデル名が必須で公開モデルが 1 つだけの場合は自動選択 |
| LLM API Key（任意） | 接続先 LLM サーバーで認証が必要な場合に入力するキー |

ポート付きの URL を貼り付けると、ポート欄へ分けて入力されます。**接続テスト・モデル取得** で接続とモデル名を確認してから **保存** してください。接続テストは推論を実行しません。

設定は ComfyUI のユーザーごとに保存され、認証情報はワークフローや PNG に含まれません。保存済みのキーは再表示されず、キー欄を空にしたまま保存すると既存のキーを保持します。

## 説明からプロンプトを作る

1. Scene Prompt (LLM) を追加します。Scene の先頭にも、既存の `scene_prompt` の続きにも置けます。
2. **モデル種別** を `Illustrious`、`Anima`、`NoobAI`、`Pony` から選び、生成したい内容と避けたい内容を書きます。
3. **プロンプト生成** を押し、結果のポジティブ・ネガティブを確認します。生成後の文章は手で編集できます。
4. Scene Prompt Expand につなぎ、通常の画像生成または **連続生成** を実行します。

Illustrious、NoobAI、Pony は英語タグ、Anima は簡潔な英語の描写を中心に変換します。モデル種別を変えた場合は再生成し、新しい出力の組を作ってください。

### 生成ボタンと保存済みの結果

| 操作 | 動作 |
| --- | --- |
| LLM ノードの **プロンプト生成** | 保存済みの結果を使わず、そのノードの説明から再生成する |
| Expand の **プロンプト生成** | 到達する LLM ノードを処理する。同じ条件の保存結果があれば手編集も含めて再利用する |
| ワークフローの読み込み、通常の画像生成、**連続生成** | 保存済みプロンプトを使う。これらの操作だけでは LLM 推論を開始しない |

プロンプト生成は、設定した LLM サービスへ説明を送ります。画像生成のキューを追加したり、接続した画像用モデルや LoRA のローダーを実行したりはしません。

同じ ComfyUI ページでの要求はクリックした順に、1 ノードずつ処理します。待機中は **待機中** と表示し、同じ待機要求を重複して追加しません。実行開始時点の入力を使い、ノードの削除・置換やワークフローの切り替えがあれば、古い結果を適用せずキャンセルします。

## Preset ごとの生成結果

Expand のプロンプト生成は Preset Reference 内の LLM ノードも対象にします。生成したプロンプトと追加した LoRA は **その Reference 固有の変更** として保存されるので、同じ共有 Preset を使う 2 つの Reference に異なる結果を持たせられます。入れ子でも参照位置ごとに独立し、子自身の変更が親からの変更より優先されます。

その Reference を **Preset編集** で開くと、固有の変更を含む内容が表示されます。そこで **保存** すると、現在編集中のルート Preset に書き込みます。共有の子 Preset 自体を変更するには、その子を開いて保存してください。実行中の画像生成は開始時の内容を使います。

## Civitai で LoRA を探す

Scene Apply LoRA の **LoRAを選択** を開き、**Civitai Search** を押します。

| 検索設定 | 選べる内容 |
| --- | --- |
| 接続先 | `civitai.red` / `civitai.com` |
| Base Model | `Illustrious` / `Anima` / `NoobAI` / `Pony` |
| 並び順 | Most Downloaded / Most Liked / Most Collected / Highest Rated |

カードをクリック、または Enter/Space で詳細を開き、画像、説明、Trigger Words、公開日、モデルとバージョンそれぞれの統計を確認します。**戻る** は元の検索結果と表示位置へ戻ります。**取得して選択** はファイルを検証して LoRA フォルダーの `llm` サブフォルダーへ保存し、ノードのモデル種別とトリガーを更新します。

検索はモデル系統ごとに行います。Pony V7 は Pony の対象には含まれません。公開 API を匿名で使うため、認証や権限が必要なファイルは取得できない場合があります。個々のモデルの利用条件は Civitai の説明で確認してください。LLM API Key はこの検索・取得には使いません。

検索語、並び順、接続先、選択は開き直しても保持します。エラー時は前の結果とノードの状態を保ち、再試行できます。ローカルファイルの詳細と **注入** の使い方は [モデルと LoRA](workflows.md#モデルと-lora)を参照してください。

### LLM 生成時の LoRA 選択

生成内容に合う LoRA を探す場合も、実際の Civitai 検索候補から LLM が選びます。取得した LoRA の Scene Apply LoRA ノードは LLM ノードの直後に追加され、後ろの接続と Queue の順序を保ちます。トリガーは LoRA 側に保存され、Expand のモデル種別が一致するときに適用されます。

## ローカル LLM と GPU メモリを共有する

ComfyUI の設定にある **Scene Prompt Tools → GPU** で、必要な場合だけ次を有効にします。どちらも初期状態は **OFF** で、ユーザーごとに保存されます。

| 設定 | 動作 |
| --- | --- |
| プロンプト生成前にComfyUIモデルを解放 | 実行中の画像生成を待ち、ComfyUI の保持モデルを解放してから LLM を使う。保存結果をすべて再利用できる場合は解放しない |
| 画像生成前にLLMモデル・KVキャッシュを解放 | 画像ジョブのノード実行前に、接続先の LLM モデルと KV キャッシュを解放する |

LLM の解放に対応するのは **Strata、Ollama、LM Studio** のリソース API です。API サーバーは停止せず、設定したモデルまたは一意に対応する読み込み済みモデルを対象にします。未対応 API、対象の曖昧さ、処理中のモデル、解放確認の失敗などは、画像ノードの実行前にエラーになります。ほかの OpenAI 互換サーバーでは、LLM 解放を OFF にしてプロンプト生成を利用してください。

プロンプト生成後に LLM を自動解放する設定ではありません。連続生成では開始時の GPU 設定を維持し、画像ジョブごとに接続先の現在の状態を確認します。接続設定の変更は次の操作から反映されます。
